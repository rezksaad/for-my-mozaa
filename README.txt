ملفات موقع عيد ميلاد قطتي

1) الصور:
   ضع 3 صور داخل مجلد images بالأسماء:
   photo1.jpg
   photo2.jpg
   photo3.jpg

2) الأغنية:
   ضع ملف الأغنية داخل مجلد music باسم:
   song.mp3

3) ارفع كل محتويات المجلد إلى مستودع GitHub بنفس ترتيب المجلدات.
   زر تشغيل الأغنية يظهر أسفل يسار الشاشة.
   الصور تظهر تدريجيًا عند النزول إليها بالتمرير.

ملاحظة: المتصفح لا يسمح غالبًا بتشغيل الأغنية تلقائيًا؛ الزائرة تضغط زر التشغيل.
